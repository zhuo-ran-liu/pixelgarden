# Pixelgarden — Image to LED Matrix Converter

**Beta version now live:**  
https://pixelgarden.cc

Turn images into beautiful LED matrix pixel art directly in the browser.

If you try it out, feedback and feature wishes are very welcome 💡

---

## Features

- Convert any image into LED matrix-style pixel art
- Adjustable matrix resolution
- Color quantization & dithering
- Live preview
- Fast, lightweight browser experience
- Export-ready output for hardware / LED projects
